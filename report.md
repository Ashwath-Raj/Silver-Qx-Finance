## Executive summary

This project implements the locked Phase 2 PS-O2 portfolio-selection problem with a depth-one QAOA circuit. It preserves the organizer's shared benchmark helpers and source data, uses an exact classical reference for the four-variable instance, and evaluates reference-penalty runs on Processors A, B and selected Processor D1. It also performs the required Processor D penalty-sensitivity sweep and Bell-state verification.

Processor D1 is a six-qubit architecture: a complete four-qubit $K_4$ asset-interaction core plus a two-edge tail. D1 was selected from three benchmarked candidate topologies because it reached the same minimum measured QAOA resource footprint as D2, used one fewer coupler than D3, and ranked first under a predeclared deterministic rule. The observed Bell-fidelity differences between candidates were small and are not claimed to be statistically significant.

All reported final experiment values below are generated by `scripts/run_final_ps_o2.py` from saved CSV outputs. The four-variable problem is classically tractable by exhaustive enumeration; this work makes no quantum-advantage claim.

## 1. Problem statement and locked formulation

PS-O2 selects exactly two assets from four binary decision variables. The organizer-locked data are:

- Expected returns: $\mu=[5,3,4,2]$
- Risk-aversion coefficient: $q=0.5$
- Cardinality: $k=2$
- Penalty sweep: $\lambda\in\{0,0.5,1,2,5,10\}$
- Number of logical qubits: four, with logical qubit $i$ representing asset $i$.

The maximization objective is

$$
F(x)=\mu^T x-qx^T\Sigma x,\qquad x_i\in\{0,1\},\qquad \sum_i x_i=2.
$$

The symmetric risk matrix $\Sigma$ and all other numeric inputs are loaded from `data/instances.json`, the authoritative locked source. The QUBO formulation minimizes

$$
E_\lambda(x)=-F(x)+\lambda\left(\sum_i x_i-k\right)^2.
$$

The squared penalty discourages bitstrings that do not select exactly two assets. Its strength is a trade-off: too small a penalty can leave an invalid state as the global QUBO minimum; increasing it reinforces feasibility but changes the cost landscape optimized by QAOA. The QUBO minimum and the measured QAOA distribution are different objects; a valid exact ground state does not imply that every sampled bitstring is valid.

## 2. Exact classical reference and baseline

The exact reference enumerates all $2^4=16$ binary strings. Six strings satisfy the two-asset constraint. For every string it computes the return-risk objective, and it checks that direct penalty evaluation matches the QUBO matrix expression.

For the locked instance, the exact feasible optimum is $F^*=4.75$, with bitstring `1100` in $x_0,x_1,x_2,x_3$ order (assets 0 and 1). The uniform-random baseline follows by enumerating the state space:

- Valid-solution frequency: $6/16=0.375$.
- Optimal-portfolio probability: $1/16=0.0625$.
- Mean objective across the six feasible portfolios: $3.625$.
- Mean feasible objective divided by $F^*$: $3.625/4.75\approx0.76316$.

These are exact classical baselines, not QAOA measurements. The full six-portfolio table is saved in `results/tables/classical_solutions.csv`; the reference $\lambda=2$ matrix is saved in `results/tables/qubo_matrix_lambda_2.csv`.

## 3. QAOA circuit and optimization procedure

The implementation uses $p=1$, with one cost layer and one mixer layer. It initializes four qubits with Hadamard gates. The cost Hamiltonian is decomposed into single-qubit RZ rotations and pairwise CX–RZ–CX sequences derived from the symmetric QUBO matrix. The mixer uses RX rotations by $2\beta$ on every logical qubit. The implementation is in `src/qaoa_circuit.py`; the constant term in the Ising representation is omitted from the circuit because it contributes only a global phase, while the full QUBO constant is retained when calculating the expected objective energy.

For every required initialization seed $0,1,2,3,4$, the starting $\gamma$ and $\beta$ are drawn independently and uniformly from $[0,\pi]$ using `numpy.default_rng(seed)`. COBYLA optimizes exact Qiskit statevector expected QUBO energy with a maximum budget of 200 objective evaluations per start. The selected result minimizes the final exact expected QUBO energy; seed is the deterministic tie-break.

At the reference penalty $\lambda=2$, the selected ideal-optimized angles are reused for the required ideal and noisy runs on A, B and D. For the D penalty-sensitivity experiment, the angles are re-optimized separately for each required $\lambda$, again using the five prescribed seeds, then used for both ideal and noisy evaluation at that $\lambda$.

## 4. Benchmark protocol and reproducibility

The implementation uses the unmodified organizer module `qff_phase2.py` for the required settings:

| Setting | Value |
|---|---|
| Basis gates | `rz`, `sx`, `x`, `cx` |
| Transpiler optimization level | 1 |
| Transpiler seed | 42 |
| Aer simulator seed | 42 |
| Shots per condition | 4,096 |
| One-qubit depolarizing rate | 0.001 |
| CX depolarizing rate | 0.005 |
| Symmetric readout bit-flip probability | 0.01 |
| QAOA depth | $p=1$ |
| Initializations | Seeds 0–4 |
| Optimizer | COBYLA; at most 200 evaluations per start |

Processor A and B maps are the fixed reference graphs defined by the organizer. Processor D uses the selected six-qubit D1 graph and must pass the official `validate_processor_d()` rules. Before the benchmark, the runner verifies the SHA-256 hashes of `qff_phase2.py` and `data/instances.json`, checks that `data/instance.json` matches the official PS-O2 fields, and validates D1. The script fails rather than silently substituting altered benchmark inputs.

The results are deterministic for a fixed environment, helper version and seeds, subject to library/version details. The official noise model is uniform synthetic noise, not a device calibration model: it does not capture qubit-specific error rates, coupler calibration, drift or crosstalk.

## 5. Processor D design and candidate selection

### Selected topology

![Selected Processor D1 coupling graph](results/figures/processor_d_topology.png)

D1 uses six physical qubits and eight undirected couplers:

`[[0,1],[0,2],[0,3],[0,4],[1,2],[1,3],[2,3],[4,5]]`

Qubits 0–3 form a complete $K_4$ graph, so all six pairwise interactions between the four asset variables have direct physical connections. The tail `0–4–5` provides a distance-three farthest pair for the required Bell-state experiment. Maximum degree is four, the graph is connected, and the gate/noise declarations match the organizer's requirements.

### Why D1 over the alternatives

![Top-three Processor D architecture comparison](results/figures/processor_d_top3_comparison.png)

The candidate sweep compared D1 (K4 plus two-edge tail), D2 (K4 plus two leaves) and D3 (K4 plus bridge vertex and leaf). The following table records the measured candidate sweep that selected D1; the final runner regenerates A/B/D and D penalty results using the selected D1 configuration.

| Metric | D1: tail | D2: two leaves | D3: bridge + leaf |
|---|---:|---:|---:|
| Physical qubits | 6 | 6 | 6 |
| Couplers | 8 | 8 | 9 |
| Compiled CX | 12 | 12 | 12 |
| CX routing overhead | 0 | 0 | 0 |
| SWAPs | 0 | 0 | 0 |
| Circuit depth | 23 | 23 | 23 |
| Two-qubit depth | 10 | 10 | 10 |
| Noisy feasible-objective yield | 0.406366 | 0.406366 | 0.406366 |
| Noisy $P_{\mathrm{opt}}$ | 0.240723 | 0.240723 | 0.240723 |
| Noisy valid frequency | 0.459229 | 0.459229 | 0.459229 |
| Farthest-pair noisy Bell fidelity | 0.949097 ± 0.002450 | 0.948120 ± 0.002472 | 0.947632 ± 0.002483 |

D1 and D2 tie on all measured QAOA quality and resource metrics in the candidate run. D1 ranked first under the predeclared rule because its farthest-pair Bell-fidelity estimate was numerically the largest. The difference from D2 is about 0.00098, far below the combined reported standard error; it is not evidence of a statistically reliable fidelity advantage. D1 is retained because it reaches the measured resource minimum with eight couplers and has a less concentrated degree distribution than the two-leaf design. D3 uses an extra coupler without an observed improvement in the benchmark.

### Expected benefit and trade-off

The four-qubit logical cost circuit has interactions between every pair of assets. A direct K4 physical core removes the need to route these interactions through a sparse logical-core coupling graph. In the candidate sweep, D used 12 compiled CX gates for 12 logical CX gates, with zero routing overhead and zero SWAPs; the compiled circuit depth was 23 versus 42 on A and 34 on B. The current project runner re-measures these metrics and writes them to `results/tables/processor_resources.csv`.

The trade-off is additional physical qubits and couplers relative to the reference devices, plus a degree-four core vertex. Higher connectivity can create more crosstalk exposure on real hardware, which the uniform synthetic noise model does not represent. The tail improves the diameter for an informative Bell test, but it does not automatically improve the four-logical-qubit QAOA distribution.

## 7. Interpretation

The key resource result from candidate selection is the compiled CX reduction to the 12-CX logical lower count, with no routing SWAPs and depth 23. The portfolio-quality result must be read separately: under the one-seed official simulation protocol, D1's valid-solution frequency was similar to or slightly higher than A/B, while its optimal-portfolio probability was not better than every reference processor. The selected architecture is therefore justified most strongly by measured connectivity/resource behavior, not by a claim that it consistently increases $P_{\mathrm{opt}}$.

The D Bell experiment evaluates both one physically adjacent pair and a graph-farthest pair. Ideal simulations should recover the target Bell correlations; under the official noise model the observed fidelity decreases, and the distant-pair experiment includes additional routing/exposure associated with connecting separated physical qubits. Bell fidelity measures a circuit primitive and is not interchangeable with portfolio objective quality.

The penalty sweep studies whether exact QUBO ground-state feasibility corresponds to the measured sampling distribution. At low $\lambda$, the exact QUBO minimum may be infeasible. At higher penalties, exact feasibility can be restored, but QAOA at $p=1$ still has finite probability mass on invalid bitstrings. The full curve and table must be interpreted together: no single penalty setting alone guarantees the highest value on every sampling metric.

## 9. Limitations and next improvements

1. **Finite shots:** reported frequencies have finite-sample uncertainty. The official protocol uses 4,096 shots, so small cross-processor differences should not be overinterpreted.
2. **Synthetic noise:** uniform depolarizing and readout errors do not model a calibrated device's connectivity-specific noise or crosstalk.
3. **Small instance:** all 16 states can be enumerated exactly; no quantum advantage is claimed.
4. **Single p value:** this required comparison uses $p=1$; greater depth would alter both the gate budget and noise exposure and should be reported as a separate experiment.
5. **Single official seed:** the required seed is preserved for comparability. More simulator seeds could be added as clearly labelled robustness experiments, but must not replace the official result.

The most defensible next improvement is repeated-seed or bootstrap analysis of the small A/B/D quality differences and, if physical calibration data become available, a device-informed noise model as a separately labelled additional experiment.
